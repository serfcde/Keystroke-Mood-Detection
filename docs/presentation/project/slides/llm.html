R06 · LLM explanation layer

The LLM sees numbers, never words

Input: structured JSON

current: speed, dwell, flight…
baseline_deviation_z: flight +2.5
recent_trend: all stable
ml_prediction: low, p = 0.99
model_reliability: CV 0.76 vs 0.25

Rules in the prompt

  • Use only the supplied numbers
  • Treat the ML output as evidence, not truth
  • Cite features and their z-scores
  • Match confidence to model reliability
  • No diagnosis

Output is a validated schema: state, agrees-with-ML, confidence, explanation, key features, uncertainty note. Without an API key a template fallback takes over.

The example values come from a held-out window in the generated run. Passing model_reliability is deliberate: the LLM is told how good the model actually is, so on the provided data it should say "low confidence" rather than parrot a 99% probability.
