Two datasets, same code

A generator lets us test the pipeline itself

Provided

  • 50 users × 20 sessions × 100 events
  • Mood re-drawn every ~1.3 keys
  • All 4 moods inside every session
  • 63% of windows labelled calm

Generated

  • Same size and schema (seed 42)
  • One mood per session; 60% carry-over
  • Per-user typing baselines
  • Injected missing, invalid, duplicate rows

The generator's effect sizes are our assumptions: it shows the pipeline can find a signal, not that keystrokes reveal mood.

7 · src/data_generator.py · MOOD_RUN=generated python -m src.model

Why two datasets: if the provided data gives near-chance results, we need to know whether the pipeline is broken or the data has no window-level signal. The generator follows the PRD's own description, with one mood per session, and the same code runs on both.
