R02 · Privacy by design

We keep how you type, never what you type

Kept

  • Dwell time: how long a key is held
  • Flight time: gap between keys
  • Pauses and corrections
  • Key category: char, space, backspace, enter, shift

Never stored

  • Letters, words, sentences
  • Anything sent to the LLM except aggregate numbers

The provided CSV contained real letters a–z. Cleaning maps them to 5 categories and drops the column before anything is saved.

3 · src/cleaning.py

Worth stressing: the dataset we were given actually broke this rule, because key_event held the real characters. We caught it in the audit and fixed it at the very first step, so nothing downstream, including the LLM, ever sees a character.
